# 社内図書貸出管理システム よくあるトラブルと対処方法

| 項目 | 内容 |
|------|------|
| 対象 | 管理者・運用担当・開発担当・一般社員 |
| 最終更新 | 2026年9月28日 |


一次対応（スーパーリロード、別端末）は [バグ対応書 第3章](./バグ対応書.md)。解消しなければ開発へ渡す。

---

## 1. 頻出（画面）

| 症状 | まずやること | 詳細 |
|------|----------------|------|
| 社員番号またはパスワードが正しくありません | 3 桁の社員番号、Caps Lock | [マニュアル 第8章](./マニュアル.md) |
| ログイン試行回数が多すぎます | 表示の秒数を待つ | 同 |
| 窓口で同じアカウントを使い回している | やめて個人アカウントでログイン | [共有アカウント管理](./共有アカウント管理.md) |
| 返却できない／社外ネットワーク | **社内 Wi-Fi**。自宅・テザリングでは場所制限にかかる | 同。仕様でありバグではないことが多い |
| ISBN が台帳にない | 管理者に資料登録を依頼 | 同 |
| すべて貸出中 | 返却待ち、または管理者が在庫追加 | 同 |
| 除名できない | 先に返却 | 同。[マニュアル](./マニュアル.md) |
| 管理権限が必要 | 管理者アカウントでログイン。管理者は `/dashboard` を使わない | [マニュアル](./マニュアル.md) |
| カメラでスキャンできない | 本番は HTTPS。HTTP なら手入力 | マニュアル 第8章 |

FAQ（自宅から借りられるか等）は [マニュアル 第7章](./マニュアル.md)、[説明資料 第10章](./説明資料.md)。

## 2. 頻出（サーバー・画面表示）

| 症状 | まずやること | 詳細 |
|------|----------------|------|
| 502 / 504 | ALB、Fargate、PHP-FPM | 同 |
| 画面の見た目が古い | スーパーリロード。`public/hot` が残っていないか、`npm run build` | [保守運用手順書 第12章](./保守運用手順書.md) |
| 管理メニューの色が無い | `npm run build`（Tailwind のスキャン漏れ） | [バグ対応書 5-2](./バグ対応書.md) |
| 設定が反映されない | `php artisan config:clear` | 同 |
| 社内なのに借りられない | グローバル IP が CIDR に入っているか | [保守運用手順書 第7章](./保守運用手順書.md) |
| Slack に期限切れが来ない | cron、Webhook、件数 0 | [保守運用手順書 第5章](./保守運用手順書.md) |
| メールが届かない | `MAIL_*`、CloudWatch Logs | [外部サービスAPI](./外部サービスAPI.md) |
| 表紙が無い | フォールバック後も無ければ手動設定 | [バグ対応書 5-2](./バグ対応書.md) |
| ディスク不足 | RDS のストレージと CloudWatch の取り込み量 | [保守運用手順書 第9章](./保守運用手順書.md) |
