## 2. できること

社内に置いてある技術書などの **登録・貸出・返却・検索** を、ブラウザ上で行うシステムです。

| 区分 | ログイン後の画面 | できること |
|------|-----------------|-----------|
| **一般社員** | 社内図書マイページ | 本棚の閲覧、借りる、返す |
| **管理者** | 管理ダッシュボード | 上記に加え、資料・利用者の登録・編集・検索・除名、期限切れ確認 |

```
ログイン
  ├─ 一般社員 → マイページ（本棚）
  └─ 管理者   → 管理ダッシュボード
```

## 3. ログイン・ログアウト

### 3-1. ログイン

1. ブラウザでシステムの URL を開く
2. **社員番号** を入力する（数字 3 桁。例: `001`）
3. **パスワード** を入力する
4. **ログイン** をクリックする

> 画面の入力欄は数字 3 桁までです。`001` と入力してください。古い形式（`EMP-0001`）で登録されたアカウントも、数字 3 桁でログインできます。**他人の社員番号でログインしない**（[共有アカウント管理](./共有アカウント管理.md)）。

### 3-2. ログイン後の遷移

| 権限 | 遷移先 |
|------|--------|
| 一般社員 | 社内図書マイページ |
| 管理者 | 管理ダッシュボード |

### 3-3. ログアウト

- **一般社員** … 画面上部の **ログアウト**、または右上の氏名 → **ログアウト**
- **管理者** … 画面右上の **ログアウト**

### 3-4. パスワードの変更

初期パスワードでログインすると、**パスワード変更画面**に進みます。変更するまで本棚や管理メニューは使えません。新規登録時の初期パスワードは、登録完了後の画面に表示されます。

| 権限 | 手順 |
|------|------|
| **一般社員** | ログイン後に表示される変更画面で、新しいパスワードを設定する。以降はマイページ上部の **パスワード変更** からも変更できる |
| **管理者** | ログイン後に表示される変更画面で、新しいパスワードを設定する。以降は右上の **パスワード変更** からも変更できる |

### 3-5. パスワードを忘れた場合（一般社員）

1. ログイン画面の **パスワードを忘れてしまった** を開く
2. 登録している **メールアドレス** を入力して送信する
3. `info@epkotsoftware.co.jp`（差出人名: 図書管理システム）から届いたメールのリンクから新しいパスワードを設定する
4. 新しいパスワードでログインする

メールが届かない場合は、迷惑メールフォルダを確認してください。管理者アカウントはメール再設定を使えません。管理者はログイン後の **パスワード変更** から設定します。

## 4. 一般社員の操作

マイページ上部に、次の 2 つのボタンがあります。

| ボタン | 用途 |
|--------|------|
| **📖 本を借りる** | 貸出カウンターへ移動する |
| **🔄 本を返す** | 自分が借りている本の一覧を開く |

その下に、社内配置ラック（本棚）が表示されます。パソコンではラックが横に広がり、一度に多くの本が見えます。各表紙の下に題名が出ます。  
本棚で表紙が実際に表示されると、その画像（または URL）が台帳に残ります。

### 4-1. 本棚から探す

1. 検索欄に **タイトル・ISBN** を入力する（入力と同時に絞り込まれます）
2. 必要なら **カテゴリ** を選ぶ
3. 書影をタップ（クリック）すると、詳細カードが開きます

#### 書影の見え方

| 表示 | 意味 |
|------|------|
| 通常の明るさ | 借りられる冊がある |
| 暗い書影 | 全冊が貸出中 |
| **在庫 N/M 冊** | 同じ本が複数冊あるときの残数 |

#### 詳細カードで分かること

- タイトル・カテゴリ・ISBN
- **借りられます** / **全冊貸出中** / **あなたは借用中**
- 在庫数

誰が借りているかは社員の本棚には出しません。督促が必要なときは管理者が資料検索・期限切れ一覧で確認します。

| ボタン | 動作 |
|--------|------|
| **この本を借りる** | 貸出カウンターへ進む（ISBN が自動入力されます） |
| **本棚に戻す** | カードを閉じる |

同じ ISBN の本をすでに借りている場合は、「同じ本は同時に 1 冊まで」と表示され、借りるボタンは出ません。

### 4-2. 図書を借りる

1. **📖 本を借りる** を押す（または本棚の詳細から **この本を借りる**）
2. 入力方法を選ぶ
   - **手入力** … 背表紙などの ISBN（10 桁または 13 桁）を入力
   - **カメラスキャン** … バーコードをカメラで読み取る
3. **貸出希望期間** を選ぶ
   - **1週間**
   - **2週間**（初期選択）
   - **1ヶ月**
4. **この条件で図書を借りる** を押す
5. マイページに戻り、成功メッセージと返却期限が表示されれば完了です

#### 借りるときの注意

- 同じ ISBN が複数冊ある場合、**空いている 1 冊** が自動で割り当てられます
- 同じ ISBN の本は、**同時に 1 冊まで** です。返却してから再度借りてください
- 台帳に無い ISBN は借りられません（管理者に資料登録を依頼してください）
- 場所制限が有効な場合、**社内ネットワークからのみ** 借りられます（[第6章](#6-運用ルール)）

#### カメラスキャンについて

- **HTTPS** の本番サイトでのみカメラが起動します。HTTP（開発用の `http://...`）では手入力を使ってください
- 初回はブラウザでカメラの使用を **許可** してください
- 読み取り対象は ISBN のバーコード（EAN-13 など）です

### 4-3. 図書を返す

1. **🔄 本を返す** を押す（件数はボタン横に表示されます）
2. 返却する本の **返却** を押す
3. 確認ダイアログで **OK** を選ぶ
4. 「図書の返却処理が正常に完了しました」と表示されれば完了です

#### 借用中一覧で確認できること

- 書籍タイトル（複数冊のときは **第N冊**）
- 貸出日
- 返却期限・残り日数
- 期限超過（赤字の警告）

借りている本が無いときは「現在借りている本はありません」と表示されます。

場所制限が有効で社外から接続している場合、返却ボタンは使えません。オフィスの指定 Wi-Fi に切り替えてから操作してください。

## 5. 管理者の操作

管理者でログインすると **管理ダッシュボード** が開きます。画面上部の **メニュー / 集計** で、操作メニューと蔵書・貸出の集計画面を切り替えます。各機能の画面からは **メニュー** で戻れます。

### 5-1. メニュー構成

#### 資料管理

| メニュー | 内容 |
|---------|------|
| 資料登録 | ISBN から書誌を取得し、1 冊ずつ台帳に追加する |
| 全資料編集 | 登録済み資料のタイトル・ISBN・カテゴリ・表紙を一括編集する。情報が古い本はここから廃棄する |
| Excel入出力 | いまの台帳を Excel で保存する。Excel / CSV から複数冊をまとめて登録する |
| 資料・利用者検索 | 蔵書と利用者の横断検索。統計も表示する |

#### 利用者管理

| メニュー | 内容 |
|---------|------|
| 利用者登録 | 社員アカウントを最大 5 名まで一括登録する |
| 利用者除名・パスワード再発行 | 社員番号または氏名で検索し、仮パスワードの再発行またはアカウント削除を行う |

#### 貸出管理

| メニュー | 内容 |
|---------|------|
| 返却期限切れ | 期限を過ぎた貸出の一覧（件数バッジあり） |

### 5-1a. 集計

画面上部の **集計** を押すと、蔵書冊数・種数・保管中・貸出中・利用率・期限切れ・まもなく期限・貸出中の人数・一般利用者数、本日の貸出・返却、今月の貸出、カテゴリ別の蔵書、よく借りられた資料、直近 14 日の貸出と返却、期限切れと 3 日以内の期限が表示されます。期限切れの詳細は **一覧を開く** から従来の画面に進みます。Grafana 本体（OSS）は使いません。

---

### 5-2. 資料登録（1 冊ずつ）

1. **資料登録** を開く
2. **ISBN（13 桁）** を入力する → OpenBD・版元ドットコム・Open Library・Google Books から書誌情報（タイトル・表紙）を自動取得します
3. 内容と **カテゴリ** を確認・修正する。検索で表紙が出ないときは **表紙画像を選ぶ** でファイルを設定できる
4. **この内容で本棚に正式登録する** を押す

#### 同じ本の在庫を増やす（2 冊目以降）

同じ ISBN を再度入力すると、「既に N 冊登録済みです」と表示されます。  
**在庫を1冊追加する（第N冊）** を押すと、空いている 1 冊として追加されます。

#### 自動取得できないとき

- **手動入力** を押し、タイトルなどを直接入力する
- ISBN 検索に失敗した場合も、手動入力フォームが開きます

ISBN は 13 桁、タイトルは必須です。

---

### 5-3. Excel入出力

台帳の保存と、Excel / CSV からの一括登録を同じ画面で行います。

#### いまの台帳を保存する

1. **Excel入出力** を開く（資料登録画面の案内からも開けます）
2. **いまの台帳をExcelで保存** を押す
3. `社内図書台帳_日付.xlsx` がダウンロードされます

シートは **一括登録用** のみです。列は題名・ISBN・カテゴリ・在庫数・表紙です。あとから同じ画面で取り込みやすい列です。

全資料編集の **Excelで保存** からも、同じファイルを落とせます。

#### 一括登録する

在庫管理表などから、まとめて登録する機能です。

1. **Excel入出力** を開く
2. **Excelから一括登録** でファイルを選ぶ（**.xlsx** 推奨、**.csv** も可）
3. 必要ならオプションを選ぶ
4. **ファイルから一括登録する** を押す

#### 列の例

| 題名 | ISBN | カテゴリ | 在庫数 |
|------|------|---------|--------|
| 独習PHP | 9784798168494 | PHP・Laravel | 2 |

- **題名は必須** です
- ISBN が空の行は、仮 ISBN（`9789999...`）で登録されます
- **在庫数** の冊数だけ登録されます（空欄は 1 冊）
- 会社の在庫管理 Excel（題名・在庫数だけ）にも対応しています

#### オプション

| 項目 | 説明 |
|------|------|
| ISBN が空の行を国立国会図書館・Google Books で自動検索する | 題名から ISBN を補完します。件数が多いと時間がかかります（1 件あたり約 1 秒） |
| 既存資料を上書き登録する | **保管中の資料を置き換えます。** Excel に無い保管中の資料は削除されます。**貸出中の冊と貸出状況、設定済みの表紙はそのまま残ります。** 通常はオフのままにしてください |

登録後、注意事項（最大 20 件）が表示されることがあります。内容を確認してください。

### 5-4. 全資料編集

1. **全資料編集** を開く
2. 必要ならキーワード（タイトル・ISBN・カテゴリ）で絞り込む
3. 各冊の **タイトル・ISBN・カテゴリ・表紙** を修正する。**ISBN を 13 桁に書き換えると、タイトル（と取れた場合は表紙）が自動で入ります**
4. 表紙は **表紙画像を選ぶ**（ファイル指定）、**表紙を再取得**（ISBN、取れないときはタイトルで OpenBD・版元ドットコム・Open Library・Google Books）、または画像 URL の入力で変更できる
5. 表紙が空の本だけまとめて探すときは **表紙がない本だけ再取得** を押す
6. **変更内容を一括保存する** を押す

#### 状態の見方

| 表示 | 意味 |
|------|------|
| 保管中 | 棚にあり、編集・廃棄できる |
| 貸出中: ○○ | 社員が借用中。返却するまで廃棄できない |
| 在庫外（Excel貸出） | Excel 上では貸出扱いになっている冊。廃棄は可能 |

#### 古い本の廃棄

情報が古くなった技術書などは、棚に残さず廃棄します。台帳に出版年はないので、**システムは自動判定しません。** 題名・版・実物の奥付で見極めます。

**見極めの順番**

1. 題名に古い版・製品名がないか見る（例: PHP 5、Laravel 5、React 16、Windows 7、Internet Explorer、Flash）
2. 実物の奥付（発行年）を見る
3. いま社内で使う技術かどうかで決める。使っていない言語・FW・試験制度は捨てる

**残す・捨てるの目安**

| 種類 | 捨てやすい例 | 残しやすい例 |
|------|--------------|--------------|
| 言語・FW・クラウド・フロント | メジャーが 2 世代以上古い。発行からおおむね 5 年超 | いまの案件で使う版 |
| 資格・試験対策 | 現行の出題範囲と合わない | いま受験する試験の版 |
| セキュリティ | 手順やツールが現行と違う（古いと誤った運用になりやすい） | 原則の説明で、現場の手順と矛盾しない |
| 設計・アルゴリズム・ビジネス・一般 | 破損や極端な誤情報 | 版が古くても考え方は使えることが多い |
| Excel・VBA | 現場が使っていない機能だけの本 | いまの業務で使う |

同じ題名で新しい版があるなら、古い版は捨てて新しい版だけ残します。迷ったら、棚に置いて誰かが古い手順で作業しないかを優先して捨てます。

**探し方**

- **全資料編集** のキーワードで、古い版名や「入門」「第1版」などを入れる
- **Excel入出力** の保存で台帳を開き、カテゴリ（フロントエンド・PHP・インフラ・資格など）ごとに題名を眺める
- 本棚で奥付の発行年を確認する

**廃棄の手順**

1. **全資料編集** を開く
2. 対象を探す
3. 対象行の **廃棄** を押す
4. 確認ダイアログで OK

貸出中の冊は廃棄できません。先に返却させてください。廃棄すると台帳と貸出履歴から外れ、本棚にも出なくなります。

### 5-5. 資料・利用者検索

1. **資料・利用者検索** を開く
2. 画面上部の統計を確認する（総資料数・保管中・貸出中・期限切れ）
3. キーワード・ステータス（すべて / 保管中 / 貸出中 / 期限切れ）・カテゴリで絞り込む
4. 一覧を下にスクロールしても検索欄は画面上部に残ります。右下の **上部へ** で先頭に戻れます

| 一覧 | 内容 |
|------|------|
| **資料一覧** | 冊ごとの表紙、タイトル、ISBN、第N冊、カテゴリ、借用者、返却期限 |
| **利用者一覧** | 社員ごとの貸出中リスト（表紙つき） |

検索対象はタイトル、ISBN、社員名、社員番号です。

### 5-6. 利用者登録

1. **利用者登録** を開く
2. 最大 **5 行** まで、社員番号・氏名・メールアドレスを入力する
   - 社員番号は数字 3 桁（例: `010`）
   - 氏名はフルネーム（例: `田中 太郎`）
   - メールアドレスは会社のアドレス（例: `taro.tanaka@example.co.jp`）
3. **入力した社員を5人まとめて一括登録する** を押す
4. 完了画面に **人ごとの仮パスワード** が出る。**パスワードをコピー**（複数名なら **全員分をコピー**）できる

空行は無視されます。入力した行だけが登録されます。社員番号・氏名・メールアドレスはセットで入力してください。

#### 自動設定される内容

| 項目 | 内容 |
|------|------|
| 仮パスワード | 登録のたびに人ごとに自動生成（この画面を閉じると再表示できない） |
| 権限 | 一般社員 |

登録後、表示された仮パスワードを本人に伝え、**パスワード変更** を案内してください。社員番号またはメールアドレスの重複は登録できません。

### 5-7. 利用者除名・パスワード再発行

退職者などのアカウント削除と、忘れたパスワードの再発行を行います。**一覧の一括表示はせず、検索してから操作** します。退職・異動の方針は [マニュアル](./マニュアル.md) です。

1. **利用者除名・パスワード再発行** を開く
2. 社員番号（`001` / `EMP-0001`）または氏名を入力して **検索**
3. 対象者の貸出状況を確認する

#### パスワードの再発行

1. **パスワードを再発行** を押し、確認ダイアログで OK
2. 画面に出た仮パスワードを本人に伝え、次回ログイン時に変更するよう案内する

貸出中でも再発行できます。

#### 除名

1. **除名処分** を押し、確認ダイアログで OK

図書を **貸出中の社員は除名できません**。先に返却を完了させてください。除名は取り消せません。

### 5-8. 返却期限切れ

1. **返却期限切れ** を開く（ダッシュボードの件数バッジでも確認できます）
2. 書籍名・借用者・社員番号・超過日数を確認する
3. 借用者に返却を促す

平日に限らず、期限切れになった時点で（最大約 1 分以内に）Slack へ通知します。同じ貸出を繰り返し送りません。管理チャンネルへ一覧、**一般利用者** の本人へ DM です。管理者には本人 DM は送りません。1 分間デモも通知対象です。

この画面から直接返却はできません。本人がマイページから返却するか、社内で現物を受け取ったうえで本人操作を依頼してください。

## 6. 運用ルール

### 6-1. 貸出・返却は社内ネットワークのみ（設定による）

場所制限が有効なとき、**借りる・返す** は指定の社内 Wi-Fi からのみ可能です。

> 図書の借りる・返却は、オフィスの社内 Wi-Fi に接続した状態で行ってください。自宅やモバイル回線からは操作できません。

- 本棚の閲覧や検索は、社外からでもできます
- 判定は Wi-Fi 名ではなく、**接続元の IP アドレス** で行います
- 社外から接続すると「社外ネットワークから接続中」と表示され、借りる／返すボタンが使えなくなります

#### 運用担当向け設定（`.env`）

```env
RETURN_LOCATION_RESTRICTED=true
RETURN_ALLOWED_NETWORKS=192.168.0.0/24
RETURN_LOCATION_NAME=オフィスWi-Fi
RETURN_ALLOW_LOCALHOST=false
```

| 環境 | 設定例 |
|------|--------|
| 社内 LAN | `192.168.1.0/24` |
| 固定グローバル IP | `203.0.113.45/32` |

変更後は `php artisan config:clear` を実行してください。本サーバーの更新は [保守運用手順書](./保守運用手順書.md) です。

### 6-2. 同じ本が複数冊ある場合

- 同じ ISBN は **冊ごとに別レコード** です
- 各冊に **第1冊・第2冊…** が付きます
- 貸出時は空いている 1 冊が自動割当されます
- 本棚では **在庫 2/3 冊** のように表示されます

在庫を増やすには、資料登録で同じ ISBN を再登録するか、Excel の在庫数を指定します。

### 6-3. 同じ本は同時に 1 冊まで

同じ ISBN の本を、同じ社員が同時に複数冊借りることはできません。返却してから再度借りてください。

### 6-4. 貸出期間

| 選択 | 返却期限 |
|------|---------|
| 1週間 | 貸出日から 7 日後（当日終了） |
| 2週間 | 貸出日から 14 日後（当日終了） |
| 1ヶ月 | 貸出日から 1 ヶ月後（当日終了） |
| 1分間デモ | 貸出から 1 分後（Slack 通知の確認用） |

延長機能はありません。期限内に返却してください。

### 6-5. 管理者の日常チェック（推奨）

1. Slack の期限切れ通知、またはダッシュボードの **返却期限切れバッジ** を確認する
2. **資料・利用者検索** で貸出状況を把握する
3. 期限切れがあれば借用者に連絡する

## 7. よくある質問

**Q. 社員番号はどのように入力しますか？**  
A. 数字 3 桁です（例: `001`）。先頭の 0 も含めて入力してください。

**Q. 初期パスワードは何ですか？**  
A. 利用者登録の完了後、人ごとに違う仮パスワードが画面へ表示されます。**パスワードをコピー** でコピーできます。このパスワードでログインすると、変更画面へ進みます。変更するまで他の操作はできません。画面を閉じると仮パスワードは再表示できません。

**Q. 自宅から本を借りられますか？**  
A. 場所制限が有効な場合、社内ネットワークからのみ借りられます。

**Q. 自宅から返却できますか？**  
A. 場所制限が有効な場合、社内ネットワークからのみ返却できます。

**Q. 同じ本が 3 冊あります。3 回スキャンが必要ですか？**  
A. いいえ。1 回の操作で空いている 1 冊が割り当てられます。

**Q. 同じタイトルを 2 冊同時に借りられますか？**  
A. 同じ ISBN は同時に 1 冊までです。別 ISBN なら借りられます。

**Q. スマホで使えますか？**  
A. はい。ブラウザから利用できます。バーコードスキャンは HTTPS 環境でカメラ許可が必要です。

**Q. カメラが起動しません。**  
A. HTTP では使えません。HTTPS の本番 URL を使うか、手入力してください。ブラウザでカメラが拒否されている場合は、アドレスバー付近から許可してください。

**Q. パスワードを忘れました。**  
A. 一般社員はログイン画面の「パスワードを忘れてしまった」から、登録メール宛のリンクで再設定します。差出人は `info@epkotsoftware.co.jp` です。管理者はこの方法は使えず、ログイン後のパスワード変更を使います。

## 8. エラーメッセージと対処

| メッセージ | 原因 | 対処 |
|-----------|------|------|
| 社員番号は必須入力です | 未入力 | 社員番号を入力する |
| 社員番号またはパスワードが正しくありません | 番号・パスワードの誤り | 3 桁の社員番号とパスワードを確認する |
| ログイン試行回数が多すぎます | 連続失敗 | 表示された秒数のあと再試行する |
| 指定されたISBNの本が台帳に見つかりません | 未登録の ISBN | 管理者に資料登録を依頼する |
| この本は現在すべて貸出中です | 全冊が借りられている | 返却を待つ |
| この本はすでに借用中です | 同じ ISBN をすでに借りている | 返却してから再度借りる |
| ISBNコードを入力するか、バーコードをスキャンしてください | ISBN 未入力 | 手入力またはスキャンする |
| 返却対象の貸出履歴が見つかりません | すでに返却済みなど | 借用中一覧を再確認する |
| 社外ネットワークから接続中 | 場所制限 | 社内 Wi-Fi に接続して再試行する |
| 貸出は○○からのみ可能です | 場所制限（借りる） | オフィスで操作する |
| 返却は○○からのみ可能です | 場所制限（返す） | オフィスで操作する |
| すでに登録されています（利用者） | 社員番号の重複 | 別の社員番号を使う |
| 貸出中のため除名できません | 未返却の本がある | 返却後に除名する |
| 「○○」は貸出中のため廃棄できません | 資料が貸出中 | 返却後に廃棄する |
| 管理者権限が必要なページです | 一般社員が管理画面にアクセスした | 管理者アカウントでログインする |
| カメラは HTTPS 接続でのみ利用できます | HTTP でスキャンしようとした | 手入力するか、本番の HTTPS を使う |

障害が続く場合は [よくあるトラブル](./よくあるトラブル.md) と [バグ対応書](./バグ対応書.md) に従って報告してください。
