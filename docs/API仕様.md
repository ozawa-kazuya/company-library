# 社内図書貸出管理システム API仕様

| 項目 | 内容 |
|------|------|
| 対象 | 開発担当・運用担当 |
| 最終更新 | 2026年9月 |

**OpenAPI（Swagger）、Postman コレクション、公開 REST の仕様書は無い。** 外向けの `api/*` も `routes/api.php` も無い。業務は **同一オリジンの Web**（Laravel + Inertia、セッション Cookie）である。

こちらが呼ぶ外部（OpenBD 等）は [外部サービスAPI](./外部サービスAPI.md)。画面の経路は [基本設計書 第6章](./基本設計書.md)。セキュリティは [セキュリティ対策](./セキュリティ対策.md)。

---

## 1. 自前の入口

| 種類 | 場所 | 仕様の書き方 |
|------|------|----------------|
| 画面・フォーム POST | `routes/web.php`、`routes/auth.php` | 基本設計 第6章。正はルートファイル |
| 管理者 ISBN 検索 | `GET /admin/books/lookup`（ログイン＋管理者） | JSON。OpenAPI ではない。基本設計 6-3 |
| 表紙画像 | `GET /covers/{id}` | バイナリ。セッションが必要 |
| 死活 | `GET /up` | Laravel 標準。本文の仕様書は無い |
| フロントのルート名 | Ziggy | JS 用。OpenAPI ではない |

`laravel/sanctum` は Composer にあるが、トークン API は業務の本線ではない。

Postman や curl で貸出 API を叩く運用は想定していない。CSRF と Cookie が前提である。
