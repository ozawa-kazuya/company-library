# 社内図書貸出管理システム データバックアップ・リストア手順

| 項目 | 内容 |
|------|------|
| 対象 | 運用担当・開発担当 |
| 最終更新 | 2026年9月28日 |
| 対象環境 | **本サーバー**（RDS MySQL） |

業務データの正は **RDS の自動バックアップ** である。Linux 1 台の `mysqldump` と `.env` ファイルコピーは本サーバーの手順ではない。位置づけは [保守運用手順書](./保守運用手順書.md)。頻度は [定期メンテナンス](./定期メンテナンス.md)。箱の定義は [AWSセットアップ](./AWSセットアップ.md)（未デプロイ）。

---

## 1. 何を残すか

| 対象 | 要否 | 方法 |
|------|------|------|
| 利用者・蔵書・貸出・表紙バイナリ | **必須** | RDS の自動バックアップ（保持 1 日の定義） |
| `APP_KEY` / DB パスワード | **必須** | Secrets Manager。イメージと Git に実値は無い |
| アプリコード | Git | バックアップに含めない |
| `vendor/` `node_modules/` | 不要 | イメージビルドで再構築 |

表紙本体は `cover_images.data`（MEDIUMBLOB）に入っている。S3 には無い。DB を戻せば表紙も戻る。

エンジンは [データベース種類.md](./データベース種類.md)。テーブル構造は [スキーマ設計とマイグレーション.md](./スキーマ設計とマイグレーション.md)。

## 2. バックアップ（本サーバー）

RDS が毎日自動で取る。アプリ更新・migrate・DB の手編集の直前は、コンソールでスナップショットを足してもよい。

| 注意 | 内容 |
|------|------|
| 保持 | 定義は 1 日。長く残すなら RDS の保持日数を上げる（課金が増える） |
| 1 AZ | その AZ が止まると DB も止まる。バックアップがあっても復旧まで貸出は止まる |
| `cdk destroy` | `removalPolicy` は DESTROY。実データがある状態で destroy すると消える |
| 別アカウントへコピー | 今回はしない |

Spatie Laravel Backup などの Composer パッケージは入れていない。AWS Backup（別サービス）は使わない。RDS 本体の自動バックアップが正である。

---

## 3. リストア（本サーバー）

戻すと **その時点の全テーブルで上書き** される。作業前に利用者へ開始時刻を伝え、新規の貸出・返却を止める（[保守運用手順書 第11章](./保守運用手順書.md)）。

1. RDS のスナップショットまたはポイントインタイムから復元する（コンソールまたは CLI）
2. 新しいエンドポイントになることがある。Secrets Manager の `DB_HOST` を直し、タスクを再起動する
3. ログイン → 本棚または管理メニュー → 貸出中・表紙が付いている本を目視する

| 状況 | そのあと |
|------|----------|
| バックアップ時点のコードと同じ | migrate は不要 |
| バックアップより新しいコードを動かしている | 不足分だけ `php artisan migrate --force`（[スキーマ設計とマイグレーション](./スキーマ設計とマイグレーション.md)、[AWSセットアップ](./AWSセットアップ.md)） |

`migrate:fresh` は使わない。誤って戻した場合は、復元直前のスナップショットへ戻す。

---

## 4. 行単位の復旧（全件リストアしない）

全 DB を戻すと、その後の正しい貸出も消える。件数が少ないときはバックアップ取得後に、管理者判断で行だけ直す。

| 状況 | 対応 |
|------|------|
| 誤返却 | `loans.returned_at` を NULL に戻す（同時に未返却が 2 件にならないこと） |
| 誤除名 | 可能なら `users` を再登録。履歴まで必要なら該当時点から抜くか全件リストア |

本番の直接 SQL はバックアップ後に限る。記録は [バグ対応書 8-3](./バグ対応書.md)。

## 5. 使わないもの

| 方法 | 本サーバー |
|------|------------|
| Linux 上の日次 `mysqldump` と `.env` コピー | 使わない（1 台構成向け） |
| AWS Backup（RDS の自動バックアップとは別サービス） | 使わない |
| Laravel のバックアップ用 Composer パッケージ | 入れていない |
| phpMyAdmin からのエクスポートだけを正とする | しない |
