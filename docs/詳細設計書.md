## 3. 処理詳細（サーバー）

### DD-01 ログイン処理

**クラス:** `LoginRequest`, `AuthenticatedSessionController`

```
1. user_code ← strtoupper(trim(input))
2. RateLimiter チェック（5 回 / キー = user_code|ip）
3. Auth::attempt({ user_code, password }, remember)
4. 失敗 → ValidationException(auth.failed)
5. 成功 → session regenerate
6. redirect:
     - isAdmin() → admin.menu
     - else → dashboard（intended クリア）
```

---

### DD-02 貸出実行（borrowExec）

**前提:** Middleware `return.location:borrow` 通過済み

```
1. ISBN 正規化
   preg_replace('/[-\s_＿]/', '', isbn)

2. バリデーション
   isbn: required, regex /^\d{10,13}$/
   duration: required, integer, in:1,7,14,30

3. 台帳存在確認
   Book::where('isbn', isbn)->exists()
   → false: error「指定されたISBNの本が台帳に見つかりません。」

4. 在庫取得
   book = Book::findAvailableCopyByIsbn(isbn)
   SQL 相当:
     SELECT * FROM books
     WHERE isbn = ?
       AND NOT EXISTS (
         SELECT 1 FROM loans
         WHERE loans.book_id = books.id AND returned_at IS NULL
       )
     ORDER BY copy_number ASC LIMIT 1
   → null: error「この本は現在すべて貸出中です。」

5. 期限計算
   duration=1  → due_date = now + 1 minute
   duration=7  → due_date = now + 7 days, endOfDay()
   duration=14 → due_date = now + 14 days, endOfDay()
   duration=30 → due_date = now + 1 month, endOfDay()

6. INSERT loans
   user_id, book_id, borrowed_at=now, due_date, duration_days

7. Redirect dashboard + success_message
```

---

### DD-03 返却実行（return）

**前提:** Middleware `return.location:return` 通過済み

```
1. loan = SELECT * FROM loans
         WHERE book_id = {bookId}
           AND user_id = auth.id
           AND returned_at IS NULL
         LIMIT 1

2. loan が null → error「返却対象の貸出履歴が見つかりません。」

3. UPDATE loans SET returned_at = now() WHERE id = loan.id

4. Redirect dashboard + success_message, active_tab=return
```

---

### DD-04 資料登録（adminBookStore）

```
1. ISBN 正規化（13 桁）

2. バリデーション（unique 制約なし）

3. copy_number = Book::nextCopyNumber(isbn)
   = COALESCE(MAX(copy_number), 0) + 1 WHERE isbn = ?

4. existingBook = 同一 ISBN の先頭レコード（cover 引継ぎ用）
   cover 未指定なら existingBook.cover を使う
   自前表紙（`/covers/{uuid}`）または URL が指定されていれば同一 ISBN の冊の cover を揃える

5. INSERT books
   isbn, copy_number, title, category, cover, status='available'

6. Redirect admin.books.create + success_message
   （2冊目以降は「第N冊・在庫追加」ラベル）
```

---

### DD-05 ISBN 検索 API（adminBookLookup）

```
入力: GET ?isbn=13桁

1. ISBN 正規化・13 桁チェック → 422

2. existingCopies = COUNT(books WHERE isbn=?)
   existingBook = FIRST(books WHERE isbn=? ORDER BY copy_number)

3. OpenBD GET（timeout 5s）
   https://api.openbd.jp/v1/get?isbn={isbn}

4. OpenBD に title / cover が無い（または通信失敗）
   → Google Books GET
   https://www.googleapis.com/books/v1/volumes?q=isbn:{isbn}

5. 分岐:
   A. OpenBD または Google Books で title あり
      → 200 + title + cover + existingCopies
      表紙は OpenBD → 版元ドットコム → Open Library → Google Books の順

   B. どちらも無し
      → existingBook あり: 200 + 登録済みメタデータ
      → なし: 404 + 手動入力案内
```

**レスポンス 200 例:**

```json
{
  "found": true,
  "isbn": "9784815608774",
  "title": "書籍タイトル",
  "cover": "https://...",
  "existingCopies": 2
}
```

### DD-06 利用者一括登録（adminUserStore）

```
foreach users[i] (i=0..4):
  emp_id = trim, name = trim

  if both empty → continue
  if one empty → errorMessages += "N行目: 両方入力"

  email = strtolower(emp_id) + '@example.com'

  if EXISTS users WHERE email OR user_code → 重複エラー

  INSERT users:
    name, email, user_code=UPPER(emp_id),
    password=生成した仮パスワード（人ごと）, must_change_password=true, role='user'

registeredCount == 0 && no errors → validation error
errors not empty → back with errors
else → admin.users.create + 人ごとの仮パスワード表示
```

### DD-07 除名（adminUserDiscardDestroy）

```
1. user = User::findOrFail(id)

2. EXISTS loans WHERE user_id=id AND returned_at IS NULL
   → true: error「貸出中のため除名不可」

3. DELETE loans WHERE user_id=id  （履歴削除）
4. DELETE users WHERE id=id

5. back + success_message
```

**除名一覧取得条件:**

```sql
SELECT * FROM users
WHERE id != 1 AND role != 'admin'
ORDER BY created_at DESC
```

## 4. 処理詳細（クライアント）

### DD-F01 本棚グループ化（bookGrouping.js）

**関数:** `groupBooksByIsbn(books)`

```
入力: Book[] （各 book に loans[] が付与）

1. Map キー = isbn || `id-${book.id}`

2. 各 book をグループに追加:
   totalCopies++
   if loans.length > 0 → borrowedCopies++
   else → availableCopies++

3. 代表 book 情報 + copies[] + 集計値を返却
```

**表示:**

- `formatStockLabel(available, total)` → 「在庫 2/3 冊」
- `formatCopyLabel(n, total)` → 「第2冊」（total > 1 のみ）

---

### DD-F02 期限表示（loanDisplay.js）

**関数:** `getLoanDisplayInfo(loan)`

```
borrowDate = loan.borrowed_at
finalDueDate = loan.due_date || borrowDate + 14日

isMinuteDemo = (finalDueDate - borrowDate) < 20分
isOverdue = finalDueDate < now

badgeText:
  超過 → 秒 / 分 / 時間 / 日（経過に応じて）
  未超過 + 1分  → "1分未満"
  未超過 + 通常 → "N日目"

durationLabel:
  duration_days=1 または isMinuteDemo → "（1分間デモ）"
  duration_days=7  → "（1週間貸出）"
  duration_days=14 → "（2週間貸出）"
  duration_days=30 または 28日以上 → "（1ヶ月貸出）"

超過表示:
  60秒未満 → "N秒超過"
  60分未満 → "N分超過"
  24時間未満 → "N時間M分超過"
  それ以上 → "N日M時間超過"
```

```

  → onSuccess: resetForm()
```

## 7. 場所制限詳細

### 7-1. ReturnLocationGuard::allows 疑似コード

```php
function allows(Request $request): bool {
    if (!config('library.return_location.restricted')) return true;

    ip = request.ip();
    if (ip === null) return false;

    if (allow_localhost && ip in ['127.0.0.1', '::1']) return true;

    networks = config('library.return_location.allowed_networks');
    if (networks is empty) return false;

    return IpUtils::checkIp(ip, networks);
}
```

interface LocationStatus {

## 8. SQL・データ操作詳細

実装は Eloquent です。生 SQL をアプリに書く範囲は [SQLとORM方針.md](./SQLとORM方針.md) です。以下は理解用の SQL 相当です。

### 8-1. 期限切れ件数（管理メニューバッジ）

```sql
SELECT COUNT(*) FROM loans
WHERE returned_at IS NULL
  AND due_date IS NOT NULL
  AND due_date < NOW();
```

### 8-2. 横断検索統計

```
total     = COUNT(books)
borrowed  = COUNT(books WHERE EXISTS active loan)
available = total - borrowed
overdue   = COUNT(books WHERE active loan AND due_date < NOW())
```

### 8-3. 複数冊：copy_number 採番

```sql
SELECT COALESCE(MAX(copy_number), 0) + 1
FROM books WHERE isbn = ?;
```

### 8-4. トランザクション方針

| 処理 | トランザクション |
|------|----------------|
| 貸出 | 単一 INSERT（現状明示なし） |
| 返却 | 単一 UPDATE |
| 資料登録 | 単一 INSERT |
| 除名 | DELETE loans + DELETE user（明示なし） |

> **改善余地:** 貸出時の同時借り競合対策に `DB::transaction` + 行ロックを検討可能。
