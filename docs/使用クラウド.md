# 社内図書貸出管理システム 使用しているクラウド

| 項目 | 内容 |
|------|------|
| 対象 | 開発担当・インフラ担当 |
| 最終更新 | 2026年9月18日 |


実行の分かれ方は [サーバーサーバレス概要](./サーバーサーバレス概要.md)。アプリが呼ぶ外部 API（OpenBD 等）は [外部サービスAPI](./外部サービスAPI.md)（ホスティングではない）。

---

## 1. 一覧

| 事業者 | 本サーバー | 備考 |
|--------|------------|------|
| **AWS** | **使う（定義あり・未デプロイ）** | ECS Fargate + ALB + RDS MySQL。[infra/](../infra/) の CDK。[AWSセットアップ](./AWSセットアップ.md) |
| さくら VPS | **使わない** | 検討した。1 台に全部載せる形。**採用しない** |
| Azure | 使わない | |
| Vercel / Netlify | 使わない | フロントは Laravel と同じプロセスで `npm run build` |
| Cloudflare Pages / Workers | 使わない | |
| Heroku / Render / Fly.io | 使わない | |
| Firebase（Hosting 等） | 使わない | |

本サーバーで使わない AWS サービス: **Lambda**、**Aurora**、EventBridge 起動の毎分タスク、**SES**、S3 表紙、WAF、NAT Gateway。

---

## 2. クラウドと紛らわしいもの

| もの | 位置づけ |
|------|----------|
| OpenBD / 版元ドットコム / Open Library / NDL | 書誌・表紙の HTTPS API |
| Google Books API | 同上。GCP 上に自前リソースは無い |
| Slack | 期限切れ通知。SaaS |
| メール（SMTP） | 社内または契約 SMTP。SES は使わない |
| Docker | 本サーバー（Fargate）用イメージは [Dockerfile](../Dockerfile) |
