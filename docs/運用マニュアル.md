## 1. どれを見るか

| 読者 | やりたいこと | 資料 |
|------|----------------|------|
| 一般社員・管理者 | 画面で借りる・返す・登録 | [マニュアル](./マニュアル.md)（版 1.0） |
| 管理者 | 同上の管理操作 | マニュアル 第5章・第6章 |
| 管理者 | 退職・異動の除名 | [マニュアル](./マニュアル.md) |
| 管理者 | 共有アカウント | [共有アカウント管理](./共有アカウント管理.md)（原則使わない） |
| 運用担当 | 死活、バックアップ、反映 | [保守運用手順書](./保守運用手順書.md) |
| 運用担当 | いつ点検するか | [定期メンテナンス](./定期メンテナンス.md) |
| 運用担当 | 壊れても戻すための3点 | [障害予防の3点](./障害予防の3点.md) |
| 運用・開発 | バックアップ / 復元 | [データバックアップリストア](./データバックアップリストア.md) |
| 全員 | 障害の切り分け | [バグ対応書](./バグ対応書.md) |
| 全員 | よくある症状 | [よくあるトラブル](./よくあるトラブル.md) |
| 開発 | リポジトリを開いたとき | [README.md](../README.md) |

## 2. 使わないもの

| もの | 使用 |
|------|------|
| 別冊の紙マニュアルを正にする | しない。`docs/` が正 |
| Notion / Confluence の運用 Wiki を正にする | しない |
| 24時間有人監視の手順書 | 無い。[基本設計書 10-2](./基本設計書.md) |

公開 API の運用（キー発行・レート制限の顧客向け手順）は無い。[API仕様](./API仕様.md)。
