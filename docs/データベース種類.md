# 社内図書貸出管理システム データベースの種類

| 項目 | 内容 |
|------|------|
| 対象 | 開発担当・運用担当 |
| 最終更新 | 2026年9月 |

**リレーショナル DB（RDB）だけ** 使います。ドキュメント指向（MongoDB）やグラフ DB はありません。

| 環境 | 種類 | 備考 |
|------|------|------|
| **本サーバー** | **RDS MySQL** | db.t4g.micro（1 AZ）。utf8mb4。[AWSセットアップ](./AWSセットアップ.md) |

切り替えは `DB_CONNECTION=mysql` です。ORM は Eloquent。テーブル定義は `database/migrations/`。構造は [基本設計書 第5章](./基本設計書.md) です。変え方は [スキーマ設計とマイグレーション.md](./スキーマ設計とマイグレーション.md) です。

---

## 1. 使わないもの

Laravel の `config/database.php` には PostgreSQL や MariaDB の接続例がありますが、**このシステムの運用対象ではありません。**

| 製品 | 使用 |
|------|------|
| PostgreSQL | 使わない |
| MongoDB | 使わない |
| Redis | キャッシュ／セッションの本線ではない（`CACHE_STORE` / `SESSION_DRIVER` は `database`） |

---

## 2. 本サーバー（RDS MySQL）

- エンジン: Amazon RDS for MySQL 8.0（db.t4g.micro、1 AZ）。Linux 1 台の mysqld も Aurora も使わない
- 文字セット: `utf8mb4` / `utf8mb4_unicode_ci`（`config/database.php` の mysql 接続）
- 置き場: 分離サブネット。Fargate からだけ届く
- 接続: Secrets Manager が渡す `DB_HOST` / `DB_DATABASE` / `DB_USERNAME` / `DB_PASSWORD`
- バックアップ: RDS の自動バックアップ（1 日）。手元の `mysqldump` は本サーバーの正ではない
- 可用性: 1 AZ。その AZ が止まると DB も止まる（費用を抑えるため）

表紙本体 `cover_images.data` は MySQL では `MEDIUMBLOB` です（マイグレーションでドライバが mysql のとき ALTER）。

---

## 3. 業務で使うテーブル

| テーブル | 内容 |
|----------|------|
| `users` | 利用者 |
| `books` | 書籍（冊単位） |
| `loans` | 貸出履歴 |
| `cover_images` | 自前表紙のバイナリ |

ほかに Laravel 標準の `sessions`、`cache`、`jobs`、`password_reset_tokens` などがあります。
