# 社内図書貸出管理システム システム仕様書・設計書

| 項目 | 内容 |
|------|------|
| 対象 | 開発担当・運用担当 |
| 最終更新 | 2026年9月 |

**`システム仕様書.md` という単一ファイルは無い。** 仕様と設計は `docs/` の複数資料に分かれる。置き場のルールは [ドキュメント管理](./ドキュメント管理.md)。ファイル名の一覧は [基本設計書 付録 B](./基本設計書.md)。

Word / Excel の仕様書、要件定義書（独立ファイル）、UML ツールのリポジトリ連携は使わない。

---

## 1. どれを見るか

上から下へ詳細になる。食い違ったらコードに合わせて `docs/` を直す。

```
説明資料（目的・権限の概要）
    → 基本設計書（機能・画面・DB・非機能）
        → 詳細設計書（処理・項目・バリデーション）
            → ソースコード
```

| 聞きたいこと | 資料 |
|--------------|------|
| リポジトリの入口 | [README.md](../README.md) |
| 何のためのシステムか | [説明資料](./説明資料.md) |
| 機能 ID（F-01 など）、画面、非機能 | [基本設計書](./基本設計書.md) |
| 実装済みかの一覧 | [主要機能一覧](./主要機能一覧.md) |
| クラス・画面項目・SQL の詳細 | [詳細設計書](./詳細設計書.md)（上位は基本設計書） |
| テーブル・migrate | [スキーマ設計とマイグレーション](./スキーマ設計とマイグレーション.md)、[基本設計書 第5章](./基本設計書.md) |
| 構成図 | [system-architecture.drawio](./system-architecture.drawio)、[サーバーサーバレス概要](./サーバーサーバレス概要.md) |
| 外部 API | [外部サービスAPI](./外部サービスAPI.md)、基本設計 第9章。OpenAPI は [API仕様](./API仕様.md) |
| 技術名 | [技術スタック一覧](./技術スタック一覧.md) |
| 画面の操作手順 | [マニュアル](./マニュアル.md)。案内は [運用マニュアル](./運用マニュアル.md) |
| よくあるトラブル | [よくあるトラブル](./よくあるトラブル.md) |
| 共有アカウント | [共有アカウント管理](./共有アカウント管理.md)（原則使わない） |
| サーバーの点検 | [保守運用手順書](./保守運用手順書.md)。案内は [運用マニュアル](./運用マニュアル.md) |
| 壊れても戻す3点 | [障害予防の3点](./障害予防の3点.md) |

基本設計と詳細設計の章の対応は、詳細設計書末尾の **付録：基本設計との対応表** である。
