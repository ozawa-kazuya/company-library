# 社内図書貸出管理システム 環境変数・シークレット管理

| 項目 | 内容 |
|------|------|
| 対象 | 開発担当・運用担当 |
| 最終更新 | 2026年9月 |
| テンプレート | ルートの `.env.production.example`（値の見本。秘密は空） |

Laravel は起動時に `.env` を読み、`config/*.php` 経由で使います。アプリコードから `env()` を直接呼ばず、`config('library.…')` 等を使います。DB の種類は [データベース種類.md](./データベース種類.md) です。**置き場とツールの方針**は [シークレット管理.md](./シークレット管理.md) です。

---

## 1. 置き場

| 環境 | 置き場 | 権限の目安 |
|------|--------|------------|
| 本サーバー（AWS） | Secrets Manager と ECS タスク定義 | IAM。手順は [AWSセットアップ](./AWSセットアップ.md) |

**Git に入れないもの**

- 実パスワード・`APP_KEY`・Slack Token

入れてよいもの: `.env.example`、`.env.production.example`（空欄またはダミー）。

チャット・チケット・画面共有に `APP_KEY`、`DB_PASSWORD`、`SLACK_BOT_TOKEN`、Webhook URL を貼らないでください。

変更後は必ず:

```bash
php artisan config:clear
```

`config:cache` している本番では、`.env` を変えたあとキャッシュを作り直すか、いったん clear します。

---

## 2. 必須（無いと起動・ログインできない）

| 変数 | 秘密 | 説明 |
|------|------|------|
| `APP_KEY` | **はい** | 暗号化・セッション。`php artisan key:generate` で作る。環境ごとに別にする |
| `APP_URL` | いいえ | 公開 URL。Slack のリンク、メール内 URL に使う |
| `APP_ENV` | いいえ | 本サーバーは `production` |
| `APP_DEBUG` | いいえ | 本サーバーは **`false`**。`true` だと例外に内部情報が出る |
| `DB_CONNECTION` | いいえ | 本サーバーは `mysql`（[データベース種類](./データベース種類.md)） |

MySQL（本サーバー）では次も必須です。

| 変数 | 秘密 | 説明 |
|------|------|------|
| `DB_HOST` | 場合による | ホスト名 |
| `DB_PORT` | いいえ | 典型は `3306` |
| `DB_DATABASE` | いいえ | DB 名 |
| `DB_USERNAME` | いいえ | 接続ユーザー |
| `DB_PASSWORD` | **はい** | 接続パスワード |

`APP_KEY` が空だと `No application encryption key` で止まります。漏洩したらキーを作り直し、既存セッションは無効になります。

---

## 3. 本サーバーで強く推奨

| 変数 | 秘密 | 本サーバーの目安 |
|------|------|----------------|
| `LOG_CHANNEL` | いいえ | **`stderr`**（CloudWatch へ出す。ファイルに残さない） |
| `LOG_LEVEL` | いいえ | `info` |
| `SESSION_DRIVER` | いいえ | `database`（migrate 済みであること） |
| `CACHE_STORE` | いいえ | `database` |
| `MAIL_MAILER` | いいえ | `smtp` 等（`log` だとメールはファイルだけ） |
| `MAIL_FROM_ADDRESS` / `MAIL_FROM_NAME` | いいえ | 再設定メールの差出人 |
| `MAIL_HOST` / `MAIL_PORT` / `MAIL_USERNAME` / `MAIL_PASSWORD` | パスワードは **はい** | SMTP 利用時 |
| `RETURN_LOCATION_RESTRICTED` | いいえ | `true` |
| `RETURN_ALLOWED_NETWORKS` | いいえ | 社内 CIDR（秘密ではないが社内設計情報） |
| `RETURN_LOCATION_NAME` | いいえ | 画面表示名 |
| `RETURN_ALLOW_LOCALHOST` | いいえ | **`false`** |
| `INITIAL_PASSWORD` | **はい** | 新規利用者の初期パスワード。既定 `password` |
| `TRUSTED_PROXIES` | いいえ | ALB 配下は **`*`**（場所制限の IP 判定に使う） |

## 4. 任意（空でも業務は動く）

| 変数 | 秘密 | 空のとき |
|------|------|----------|
| `SLACK_OVERDUE_WEBHOOK_URL` | **はい** | 管理チャンネルへ送らない |
| `SLACK_BOT_TOKEN` | **はい** | 本人 DM しない（`xoxb-` で始まる） |
| `GOOGLE_BOOKS_API_KEY` | **はい** | Google Books の無認証枠 |
| `RETURN_LOCATION_DENIAL_MESSAGE` | いいえ | 既定の拒否文 |
| `VITE_APP_NAME` | いいえ | フロントの表示名 |

Slack・メールの呼び出し先は [外部サービスAPI](./外部サービスAPI.md) です。

## 5. 本サーバー（AWS）の例

タスク定義と Secrets Manager で渡す。イメージに `.env` は焼かない。

```env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://library.example.co.jp
DB_CONNECTION=mysql
LOG_CHANNEL=stderr
TRUSTED_PROXIES=*
SESSION_SECURE_COOKIE=true
RETURN_LOCATION_RESTRICTED=true
RETURN_ALLOW_LOCALHOST=false
MAIL_MAILER=smtp
SESSION_DRIVER=database
```

`APP_KEY` と `DB_PASSWORD` は Secrets Manager。開発用のキーを本番にコピーしない。変数名の見本は `.env.production.example`、手順は [AWSセットアップ](./AWSセットアップ.md)。

## 6. 業務設定（`config/library.php`）

| `.env` | config キー |
|--------|-------------|
| `RETURN_LOCATION_*` | `library.return_location.*` |
| `INITIAL_PASSWORD` | `library.initial_password` |
| `SLACK_OVERDUE_WEBHOOK_URL` | `library.slack.overdue_webhook_url` |
| `SLACK_BOT_TOKEN` | `library.slack.bot_token` |
| `GOOGLE_BOOKS_API_KEY` | `library.google_books_api_key` |

確認:

```bash
php artisan config:show library
```

パスワードや Token の値は端末のログに残るので、共有するときはマスクします。

---

## 7. 運用ルール

1. 中身をチャットに貼らない
2. `APP_KEY` は環境ごとに `key:generate`
3. 本サーバーの秘密は Secrets Manager。Git とイメージに実値を入れない
4. 担当変更時は Slack Token・DB パスワード・初期パスワードのローテーションを検討する
5. `APP_DEBUG=true` の本番公開はしない
