## 1. 結論

業務アプリのコードは **1 本** です。実行の置き方は **本サーバー（AWS）** です。**サーバレス Lambda は使いません。** 本サーバーは Fargate で常時稼働する（定義あり・未デプロイ）。

| | 本サーバー（AWS） |
|--|-------------------|
| 種類 | **サーバー**（ECS Fargate。常時稼働） |
| 置き場 | ALB + Dockerfile の Nginx + PHP-FPM |
| DB | RDS MySQL |
| 定期処理 | コンテナ内で毎分 `schedule:run` |
| ログ | CloudWatch（stderr） |
| 反映 | `cdk deploy`（未実施） |
| 秘密 | Secrets Manager |


```
同じアプリコード（app / resources / routes / database）
        │
        └─ 本サーバー …… AWS（ALB + Fargate + RDS MySQL）。未デプロイ
```

## 2. Git 上のコードの分かれ方

```
company-library/
│
├── 【本サーバーでも使う・アプリ本体】
│   ├── app/                  PHP（業務ロジック）
│   ├── routes/               URL とスケジュール
│   ├── resources/js/         React（画面）
│   ├── database/             マイグレーション・シーダー
│   ├── config/               Laravel 設定（library.php など）
│   ├── public/               公開ディレクトリ（build 済みフロント含む）
│   ├── tests/                PHPUnit
│   ├── composer.json         PHP 依存
│   └── package.json          フロント依存
│
├── 【本サーバー（AWS）】
│   ├── Dockerfile
│   ├── docker/
│   ├── infra/                CDK
│   ├── .env.production.example（変数の名前の見本。実値は Secrets Manager）
│   └── docs/AWSセットアップ.md
```

`vendor/` と `node_modules/` は依存パッケージです。本サーバーではイメージビルド時に `composer install` / `npm ci` する。Git に含めない想定です。

`.env` には秘密情報が入ります。リポジトリにコミットしません。

## 3. アプリ本体（共通コード）の概要

モノリシックな Laravel + Inertia + React です。REST API 専用の別サービスはありません。

### 3-1. サーバー側（PHP）

| パス | 役割 |
|------|------|
| `app/Http/Controllers/BookController.php` | 本棚・貸出・返却・管理 CRUD・検索 |
| `app/Http/Controllers/CoverImageController.php` | 表紙の保存・表示・再取得 |
| `app/Http/Controllers/Auth/` | ログイン・パスワード再設定 |
| `app/Http/Middleware/EnsureAdmin.php` | 管理者のみ |
| `app/Http/Middleware/EnsureReturnLocation.php` | 社内 IP での貸出・返却制限 |
| `app/Models/` | `User` / `Book` / `Loan` / `CoverImage` |
| `app/Services/BookIsbnLookup.php` | OpenBD 等の書誌取得 |
| `app/Services/GoogleBooksLookup.php` | Google Books |
| `app/Services/NdlBookLookup.php` | 国立国会図書館の表紙 |
| `app/Services/OverdueSlackNotifier.php` | 期限切れ Slack 通知 |
| `app/Services/ReturnLocationGuard.php` | 場所制限の判定 |
| `app/Console/Commands/NotifyOverdueSlackCommand.php` | `library:notify-overdue-slack` |
| `routes/web.php` | HTTP ルート |
| `routes/console.php` | 毎分のスケジュール |
| `config/library.php` | 場所制限・初期パスワード等 |

### 3-2. 画面（React）

ビルド結果は `public/build/` に出ます。本サーバーでは `npm run build` が必要です。

| パス | 画面 |
|------|------|
| `resources/js/Pages/Dashboard.jsx` | 一般社員の本棚 |
| `resources/js/Pages/BorrowScan.jsx` | 貸出 |
| `resources/js/Pages/ReturnList.jsx` | 返却 |
| `resources/js/Pages/Admin/` | 管理メニュー・資料・利用者・期限切れ |
| `resources/js/Pages/Auth/` | ログイン・パスワード |

### 3-3. データ

| パス | 内容 |
|------|------|
| `database/migrations/` | `users` / `books` / `loans` / `cover_images` 等 |
| `database/seeders/` | 初期データ |

本サーバーは RDS MySQL です。接続先は環境変数の `DB_*` です。種類の整理は [データベース種類.md](./データベース種類.md) です。スキーマ変更は [スキーマ設計とマイグレーション.md](./スキーマ設計とマイグレーション.md) です。

### 3-4. リクエストの流れ

```
ブラウザ
  → ALB
    → PHP / Laravel（Fargate 上の Nginx + PHP-FPM）
      → 認証・管理者・場所制限のミドルウェア
        → Controller
          → Model / Service
            → RDS MySQL
```

外部へは次だけ出ます。

- 書誌・表紙: OpenBD / Google Books / NDL
- 期限切れ: Slack
- パスワード再設定: メール

## 4. 本サーバー（AWS）

常時起動しているのは Fargate タスクである。EC2 の OS は自分で見ない。Linux 1 台への配置はしない。定義は [Dockerfile](../Dockerfile) と [infra/](../infra/)。未デプロイ。

| 項目 | 内容 |
|------|------|
| 入口 | ALB |
| 実行 | ECS Fargate（Nginx + PHP-FPM 8.3+） |
| アプリ | イメージ（ECR） |
| DB | RDS MySQL（分離サブネット、db.t4g.micro） |
| 定期処理 | コンテナ内の毎分 `schedule:run` |
| ログ | CloudWatch Logs（`LOG_CHANNEL=stderr`） |
| 秘密 | Secrets Manager |


スケジュール本体は `routes/console.php` です。期限切れ Slack を 1 分ごとに実行します。初回は [AWSセットアップ](./AWSセットアップ.md)。反映はイメージの作り直しとタスク更新。毎回の起動で migrate は走らせない。

## 5. Git 運用の目安

本サーバーへの反映は Git の内容をイメージに焼いて載せる前提です。

| 含める | 含めない |
|--------|----------|
| `app/` `resources/` `routes/` `database/` `docs/` | `.env` |
| `.env.example` `.env.production.example` | `vendor/` `node_modules/`（ルートと `infra/`） |
| `Dockerfile` `docker/` `infra/`（`cdk.out` 以外） | `infra/cdk.out` |
| `composer.lock` `package-lock.json` `infra/package-lock.json` | `storage/logs/` |
| `tests/` | — |

ロールバックは [バグ対応書 8-2](./バグ対応書.md) を参照してください。
