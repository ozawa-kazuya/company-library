## 0. 説明文（読み上げ用）

社内図書はブラウザで動く Web アプリです。ネイティブアプリも、外向けの REST API もありません。サーバーは PHP 8.3 と Laravel 13 です。画面は React 18 です。ページ遷移は Inertia.js で、Laravel が HTML と一緒に React のページを返します。別サーバーの SPA ではありません。見た目は Tailwind CSS、フロントのビルドは Vite です。認証は Laravel Breeze のセッション Cookie です。社員番号とパスワードでログインします。Sanctum のトークン API は画面では使いません。

データベースはリレーショナルだけです。本サーバーは RDS MySQL です。PostgreSQL も MongoDB も Redis も Aurora も使いません。業務テーブルは利用者、書籍、貸出、表紙の 4 つです。ORM は Eloquent です。Excel の取り込みは PhpSpreadsheet を使わず、PHP 標準の Zip と CSV です。

本サーバーの実行環境は AWS です。入口が ALB、計算が ECS Fargate（ARM 0.25 vCPU / 512MB）、データが RDS MySQL（db.t4g.micro）、秘密が Secrets Manager、ログが CloudWatch Logs です。コンテナの中は Nginx と PHP-FPM です。期限切れ Slack はコンテナ内で毎分回します。Lambda は使いません。

外部は書誌と表紙の API、Slack、メールだけです。書誌は OpenBD を優先し、足りなければ版元ドットコム、Open Library、Google Books、国会図書館です。メールは社内または契約の SMTP です。SES は使いません。監視の New Relic や Grafana、エラーの Sentry は入れていません。死活は `/up` です。

依存の正は `composer.lock` と `package-lock.json` です。詳細の表は本資料の以降の章です。

## 6. 実行環境（本サーバー ＝ AWS）

| 層 | 技術 |
|----|------|
| 入口 | ALB（HTTPS:443。HTTP は転送） |
| 計算 | ECS Fargate ARM（0.25 vCPU / 512MB。Nginx + PHP-FPM 8.3+） |
| DB | RDS MySQL（db.t4g.micro、1 AZ） |
| 定期処理 | コンテナ内の毎分 `schedule:run`（[定期メンテナンス](./定期メンテナンス.md)） |
| ログ | CloudWatch Logs（[ログ管理](./ログ管理.md)） |
| 秘密 | Secrets Manager |
| 課題管理 | アプリ連携なし（[バグ課題管理](./バグ課題管理.md)） |
| HTTPS | ACM を ALB で終端。コンテナ内は HTTP |

本サーバーでは Fargate 用 [Dockerfile](../Dockerfile) を使う。

Linux 1 台（Apache / Nginx + 同じマシンの MySQL）は採用しない。

## 7. 外部サービス（本サーバーからも利用）

エンドポイントと障害時の扱いの詳細は [外部サービスAPI.md](./外部サービスAPI.md) です。

アプリが HTTPS で呼ぶ外部です。自前でホストしません。

| サービス | 用途 | 備考 |
|----------|------|------|
| OpenBD | ISBN の書誌・表紙 | 優先 |
| 版元ドットコム | 表紙 | OpenBD の次 |
| Open Library | 表紙 | その次 |
| Google Books API | 書誌・表紙 | キーは任意（`GOOGLE_BOOKS_API_KEY`） |
| 国立国会図書館（NDL） | 題名から ISBN | OpenSearch |
| Slack Incoming Webhook | 期限切れの管理チャンネル | 未設定なら送らない |
| Slack Bot API | 一般利用者への DM | メール一致が必要 |
| メール（SMTP 等） | パスワード再設定 | `.env` の `MAIL_*` |

クライアント（ブラウザ）からも Google Books を検索する画面があります（`BookSearch.jsx`）。
