# 社内図書貸出管理システム セキュリティ対策

| 項目 | 内容 |
|------|------|
| 対象 | 開発担当・運用担当 |
| 最終更新 | 2026年9月 |

社内向けの **同一オリジン Web アプリ**（Laravel + Inertia + React）である。公開 REST API は出していない（[API仕様](./API仕様.md)）。秘密の置き場は [環境変数とシークレット](./環境変数とシークレット.md)。DB アクセスは [SQLとORM方針](./SQLとORM方針.md)。

---

## 1. 要約

| 脅威 | 対策 | 本線か |
|------|------|--------|
| CORS | 業務画面は同一オリジン。CORS 設定ファイルはリポジトリに無い | ほぼ対象外（下記） |
| SQL インジェクション | Eloquent のプレースホルダ。アプリに生 SQL を書かない | **本線** |
| XSS | React のテキスト描画（エスケープ）。`dangerouslySetInnerHTML` は画面コードに無い | **本線** |
| CSRF | Laravel の CSRF トークン + セッション Cookie（`SameSite=lax`、`HttpOnly`） | **本線** |
| 権限昇格 | `EnsureAdmin`。場所制限は `EnsureReturnLocation`（サーバー側） | **本線** |
| 認証総当たり | ログイン失敗 5 回でロックアウト。再設定メールは `throttle:6,1` | **本線** |

フロントの `disabled` は UX だけである。借りる・返す・管理はサーバーで弾く。

---

## 2. CORS

業務の画面遷移と POST は **同じホスト**（Inertia）である。ブラウザが別オリジンからこのアプリの Cookie 付き API を呼ぶ設計ではない。

Laravel 同梱の CORS（`HandleCors`）は、未公開の既定 `config/cors.php` どおり **`api/*` と `sanctum/csrf-cookie` だけ** が対象である。このアプリは `routes/web.php` が本線で、公開の `api/*` は無い。`config/cors.php` はプロジェクトにコピーしていない。

別ドメインの SPA からこのサーバーを叩く構成にするときは、そのときに CORS を設計する。現状は不要である。

`laravel/sanctum` は Composer にあるが、ログインは **セッション Cookie** である。トークン API は業務の本線ではない。

---

## 3. SQL インジェクション

- 条件は `where('isbn', $isbn)` のようにバインドする
- コントローラ／サービスに SQL 文字列の連結を書かない
- 生 SQL はマイグレーションの例外だけ（例: MySQL `MEDIUMBLOB`）

詳細は [SQLとORM方針](./SQLとORM方針.md)。

---

## 4. XSS

- 書籍名・氏名などは React の子要素として出す（既定でエスケープ）
- `resources/js` に `dangerouslySetInnerHTML` は無い
- パスワード・表紙バイナリはモデルの `hidden` で JSON に出さない
- 表紙 URL の自前保存は許可ホストだけ（`CoverSourceGuard`。SSRF 対策を兼ねる）

---

## 5. CSRF・セッション

| 項目 | 内容 |
|------|------|
| CSRF | `web` ミドルウェアの検証。Inertia がトークンを付ける |
| Cookie | `HttpOnly`（既定 true）、`SameSite=lax` |
| Secure | HTTPS 本番では `SESSION_SECURE_COOKIE=true` を推奨 |
| パスワード | bcrypt。初期パスワードは初回変更を求める |

本サーバーは HTTPS（[基本設計書 10-3](./基本設計書.md)）。`APP_DEBUG` は本番 `false`。

---

## 6. 認可・入力・その他

| 項目 | 内容 |
|------|------|
| 管理者画面 | ミドルウェア `admin`（`EnsureAdmin`） |
| 貸出・返却の場所 | `return.location`（CIDR。フロントだけでは迂回できない） |
| バリデーション | FormRequest / `$request->validate`（ISBN、画像 mime と 2MB など） |
| 表紙表示 | `GET /covers/{id}` はログイン必須 |
| 表紙の外部取得 | 許可ドメイン以外の URL は保存しない |
| ログイン | 社員番号 + パスワード。失敗 5 回でレート制限。共有アカウントは使わない（[共有アカウント管理](./共有アカウント管理.md)） |
| `/register` | Breeze 由来で残る。運用上の利用者追加は管理画面（[主要機能一覧](./主要機能一覧.md)） |

`User` は現状 `$guarded = []`。新規モデルは `fillable` を付ける。

WAF や独自の CSP ヘッダはこのアプリでは設定していない。HTTPS とサーバー側の TLS は Web サーバーの設定である。
