# 社内図書貸出管理システム

社内の技術書・ビジネス書などの **貸出・返却・在庫** をブラウザで管理する Web アプリです。紙や Excel の台帳の代わりに使います。

本サーバーは **AWS**（ALB + ECS Fargate + RDS MySQL）です。定義は [AWSセットアップ](docs/AWSセットアップ.md)。**まだデプロイしていません。** 公開 REST API はありません。

詳細な手順・設計の正本は [`docs/`](docs/) です。置き場のルールは [ドキュメント管理](docs/ドキュメント管理.md) です。

---

## できること

| 利用者 | 内容 |
|--------|------|
| 一般社員 | 本棚の閲覧、ISBN / バーコードで借りる、返却（社内ネットワークのみ、場所制限が有効なとき） |
| 管理者 | 資料・利用者の登録、横断検索、期限切れ確認、除名。本棚（`/dashboard`）は使わない |
| 自動 | 毎分の期限切れ Slack（チャンネル。メール一致時は一般へ DM） |

認証は社員番号（画面は数字 3 桁）+ パスワード、セッション Cookie です。1 人 1 アカウントです（[共有アカウント管理](docs/共有アカウント管理.md)）。機能の一覧は [主要機能一覧](docs/主要機能一覧.md)、外部 API は [外部サービスAPI](docs/外部サービスAPI.md) です。

未実装: 年度末処理、貸出予約、設定 GUI、管理者の代理返却。

## 本サーバー

本サーバー ＝ AWS。反映はイメージを ECR に載せてタスクを更新する（[AWSセットアップ](docs/AWSセットアップ.md)）。死活は ALB 配下の `/up`。期限切れ Slack はコンテナ内の毎分 `schedule:run`。Linux 1 台への `git pull` は本サーバーの手順ではない。
